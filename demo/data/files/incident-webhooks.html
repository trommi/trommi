Incident report · payments-service

Renewal webhooks were dropped for 38 minutes

A deploy changed how the webhook endpoint reads the request body. The signature check then failed for every event, and Stripe's events were answered with 400. Nobody was charged twice; 212 renewals were late.

Why it happened

The signature is computed over the raw body. The new JSON parser handed the route a parsed object, so the check compared against a re-serialised string. The test for the route used a fixture that bypassed the parser.
