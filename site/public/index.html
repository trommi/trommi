What it does

  • Mobile control. Your agents keep working at the desk; you answer, chat and approve from wherever you are.
  • Agents ask, you decide. A session files a card with its question and a few options; one tap answers.
  • A push when one needs you. The blocking questions come first; the rest waits.
  • End-to-end encrypted. The server delivers sealed envelopes and holds no key that opens them.
  • Open source. App, connector and server are on GitHub.

Connect an agent

On a machine with Claude Code or Codex, on Linux or macOS. Once per machine, install the connector:

curl -fsSL https://raw.githubusercontent.com/trommi/trommi/main/install.sh | sh

Then in Claude Code, in a project folder, with the invite link from Invite Agent… in the app (in Codex, ask the agent to connect with the link):

/trommi:connect 'the invite link'

Compare the six emoji in the terminal and in the app, confirm, and the session's next question lands on your Desk.
